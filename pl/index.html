O mnie

Pasjonat rozwiązywania problemów z ponad 10-letnim doświadczeniem zawodowym. Moja przygoda rozpoczęła się 15 lat temu od nauczenia się C++ w celu analizy cen akcji na giełdzie przy pomocy uczenia maszynowego, ostatecznie przechodząc na .NET, gdzie odnalazłem powołanie. Stawiam na przejrzystość, łatwość utrzymania i realny wpływ.

Poza pracą etatową rozwijam narzędzie do analizy giełdowej Stock-Today, pełnię funkcję CTO platformy quizowej Squizzu, utrzymuję wiele bibliotek open source i prowadzę bloga False Green o wpadkach agentów AI przez nich samych.

Własne projekty

Rozwijam narzędzie do analizy szeregów czasowych cen akcji polskich i zagranicznych spółek, z użyciem algorytmów uczenia maszynowego, metod statystycznych oraz analizy technicznej i fundamentalnej. Backend napisany w C# odpowiada za synchronizację danych, wykonywanie analiz, generowanie raportów i wysyłanie wyników do repozytorium, gdzie GitHub Action uruchamia wdrożenie statycznej strony do Azure, dając zerowy koszt utrzymania. Aktualne wyniki: Stock-Today.

Pełnię funkcję CTO w Squizzu, platformie quizowej budowanej w React i C# z wykorzystaniem generatywnej AI. Zaprojektowałem i zaimplementowałem model danych, skonfigurowałem integracje z CosmosDB i Key Vault, odpowiadam też za integrację z Azure OpenAI.

Piszę i publikuję False Green, bloga o weryfikacji, która wyglądała na zieloną, a nią nie była — każdy wpis to prawdziwy incydent, w którym test przeszedł, a system nadal był zepsuty. Statyczna strona w Astro, wdrażana na Azure Static Web Apps przez GitHub Actions, na infrastrukturze opisanej w Terraform.

Utrzymuję publiczny zestaw skilli do Claude Code — ponad 30 powtarzalnych procesów do code review, triage'u, przekazywania pracy i higieny wydań, instalowanych jako plugin Claude Code.

Próbowałem również innych przedsięwzięć, w tym platformy kursów online i narzędzia do raportowania czasu pracy zbudowanego w Power Apps. Chociaż te projekty nie osiągnęły długoterminowego sukcesu, dostarczyły cennych lekcji i umiejętności, takich jak znajomość Power Platform.

Wybrane biblioteki open source, które rozwijam i utrzymuję:

  • LoggerLite — Lekki framework do logowania obsługujący JSON, XML, YAML, konsolę i pliki, z wbudowanym debouncingiem.
  • OnTheFlyStats — Umożliwia obliczanie statystyk w locie, takich jak średnia czy wariancja, z dostępem w czasie O(1).
  • Extensions.Standard — Kolekcja metod rozszerzających do typowych zadań, takich jak interpolacja czy partycjonowanie.
  • ProgressReporting — Biblioteka do szacowania pozostałego czasu i raportowania postępu pętli lub transferu danych.
  • StocksData — Biblioteka .NET Standard do symulowania strategii giełdowych na historycznych danych rynkowych. Na NuGet opublikowana jako pakiety Stocks.Data.*.

Te i inne pakiety są dostępne na NuGet.org.
